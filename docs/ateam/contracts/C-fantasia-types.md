# C-fantasia-types: Shared Blueprint-visible types and module entry
- As of: J-0027
- Version: 1
- Provider: M-core
- Consumers: M-tts, M-llm, M-prolog, M-probabilistic, M-ml, M-neo4j, M-ace, M-demo, M-tests
- Tests: FANTASIA/Source/FANTASIATests/Private/FANTASIATypesTests.cpp
- Provenance: recovered

## Specification

Headers: `FANTASIA.h`, `FANTASIATypes.h`. Everything here is `UCLASS`, `USTRUCT`,
`UENUM` or a dynamic multicast delegate, so it is part of the Blueprint ABI: a change
to any of it invalidates compiled Blueprint assets in every project that uses the
plugin.

Module entry, consumed by the engine and by the export macro every public class carries:

- `class FFANTASIAModule : public IModuleInterface` — `StartupModule()`,
  `ShutdownModule()`. Load timing comes from `LoadingPhase` in the `.uplugin`.
- `FANTASIA_API` is **not** part of this contract. It is generated by UBT from the
  module descriptor, so it belongs to C-build, and it is applied unevenly: neither
  `FFANTASIAModule` nor any `USWIProlog*` class in `FANTASIATypes.h` carries it, and
  nor do `UElevenLabsTTSComponent`, `FBoltStructure`, `FElevenLabsVoiceSettings` or the
  Bayesian structs. A type without it cannot be used from another module.

Prolog term model, consumed by M-prolog, M-demo, M-tests:

- `enum class SWIPrologOperation : uint8`
- `USWIPrologObject : UObject`; `USWIPrologRuleBody` (`firstRule`, `secondRule`,
  `prologOperator`); `USWIPrologRule` (`head`, `body`)
- `USWIPrologTerm : USWIPrologObject`, and its subclasses `USWIPrologAtom`
  (`atomValue`), `USWIPrologVariable` (`varName`), `USWIPrologInteger` (`intValue`),
  `USWIPrologFloat` (`floatValue`), `USWIPrologCompound` (`compoundName`,
  `arguments`), `USWIPrologList` (`elements`), `USWIPrologHeadToTail`
  (`headElements`, `tail`), `USWIPrologCut`
- `USWIPrologSolution : UObject` (`resultSet`, `verified`)
- `FSWIPrologResponse` (`queryName`, `arity`, `results`)

Chat model, consumed by M-llm, M-demo, M-tests:

- `enum class GPTRoleType : uint8` — `SYSTEM`, and the remaining roles
- `FChatTurn` (`role` defaulting to `USER`, `content` defaulting to the empty string)
- `FIncomingGPTResponseEvent(FString GPTResponse, GPTRoleType role)`
- `FIncomingGPTStreamResponseEvent(FString GPTResponse, GPTRoleType role, bool endStream)`

Probabilistic model enums, consumed by M-probabilistic:

- `InfluenceNodeType`, `BayesianNodeType`, `InferenceAlgs`, `InferenceIDAlgs`

Speech synthesis model, consumed by M-tts, M-ace, M-tests:

- `TTSVoiceType`
- `FTTSTimedStruct` (`time`, `data`)
- `FTTSSegmentTiming` (`Text`, `StartSeconds`, `EndSeconds`, `CharStart`, `CharEnd`) —
  captured internally, not Blueprint-exposed (ADR-0010)
- `FTTSData`
- `FSynthesizedEvent(FString id)`, `FPartialSynthesizedEvent(FString id)`, and the
  internal variants `FSynthesizedInternalEvent(FTTSData response, FString id)` and
  `FPartialSynthesizedInternalEvent(FTTSData response, FString id)`

Graph data model, consumed by M-neo4j, M-demo, M-tests:

- `Neo4jOperation`
- `FNeo4jResponse` (`transactionID`, `headers`, `rows`)
- `UNeo4jResultRow` (`cells`, a name-to-cell map)
- `UNeo4jResultCell`, and its subclasses `UNeo4jResultCellNode` (`labels`, `id`,
  `properties`), `UNeo4jResultCellRelationship` (`label`, `id`, `properties`),
  `UNeo4jResultCellSimple` (`value`)

## Errors

None. This contract is data and a module interface; it has no failure channel. Result
carriers report outcome in their own fields: `USWIPrologSolution::verified` says whether
a solution holds, and `FSWIPrologResponse::results` is empty when a query found nothing.

## Invariants

- Every type here is reflected. Renaming, reordering an enum, retyping a property or
  changing a delegate signature breaks compiled Blueprints in user projects, so each is
  a major change under P-03 regardless of how small the diff looks.
- `FChatTurn` defaults to the `USER` role and empty content; `FTTSSegmentTiming` and
  `FTTSData` default to zeroed fields. The defaults are pinned by
  FANTASIATypesTests.cpp and are what Blueprint nodes show when a pin is unconnected.
- Enum values are positional: appending is safe, inserting is not.
- `M-core` holds no state beyond the module object and reaches no other module.
- Types in this contract belong to five different components' vocabularies. That is a
  recorded defect, not a design intent (F-001): the contract describes what is.
- `FWhisperConfig` and the Whisper types are **not** part of this contract; they belong
  to C-asr. `FSVMParameters` belongs to C-math, and `FElevenLabsVoiceSettings` to
  C-elevenlabs-protocol, even though FANTASIATypesTests.cpp exercises their defaults
  alongside these.
